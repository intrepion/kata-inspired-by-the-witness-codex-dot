# Pause suspends the current garden session

Leaving or completing a tablet ends tracing and resumes exploration; Escape and focus loss suspend whichever mode is active. Keep one explicit interaction state containing the active panel, unfinished trace, return mode and mouse-capture lifecycle so pause cannot silently cancel a puzzle, and delayed unlock events cannot turn a deliberate exit into a pause. Browser capture denial is an active-exploration condition with an inline click prompt, rather than a separate pause transition.
